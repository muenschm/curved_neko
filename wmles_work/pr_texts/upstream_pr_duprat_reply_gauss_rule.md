Yes, `zwgl` in `speclib` provides the rule (`space_t` calls it for GL spaces; we use it directly, since only the 1D rule is needed). The model now computes the 5-point rule once at initialisation, maps it to [0, 1] and passes it to the kernels of all backends, so the hard-coded tables are gone from the CPU and the device code. The rule is independent of the polynomial order of the flow solver: it integrates the model's 1D profile in ln(1 + y*), so we call `zwgl` with a fixed number of points rather than reuse the space of the simulation. The results are unchanged to round-off. Done in 7cd115e.
